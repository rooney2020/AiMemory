# AI Memory 路线图

## 一、当前状态

| 模块 | 状态 | 说明 |

## 二、近期重点

### 1. 文档与规则一致性

- 保持 README、集成指南、Cursor 规则、Qt 前端文档与真实实现一致
- 减少历史设计残留，避免命令名、入口、目录结构再次过期
- 持续补齐 `entities`、图谱同步、多 AI 助手适配说明

### 2. CLI 体验完善

- 持续保持子命令命名稳定
- 补充更清晰的输出约定与错误提示
- 让规则文档中的命令示例严格对应实际参数

### 3. 图谱质量提升

- 提升历史记忆补实体的效率
- 优化 `rebuild-graph` 的预览与统计说明
- 继续完善实体命名、别名归一和关系质量

### 4. 资产复用闭环

- 强化资产注册、查找、复用、失效标记的工作流说明
- 保持资产与记忆之间的可追踪关系
- 减少重复产物和重复劳动

### 5. Qt 工作台打磨

- 持续优化搜索、图谱、会话记录和资产视图
- 维持 Cursor、OpenClaw、Toder、Copilot 等会话来源兼容性
- 继续完善部署说明、启动脚本和 Linux 运行稳定性

---

## 三、中期方向

1. 提升规则与文档在不同 AI 助手之间的复用性。
2. 持续压缩历史遗留设计稿，保留对当前实现真正有价值的说明。
3. 在不破坏现有 CLI 的前提下补充更细粒度的运维与排障文档。
4. 继续完善测试覆盖，尤其是图谱重建、资产管理和会话解析链路。
