# Qt 前端设计说明

> 本文档保留为当前 Qt 工作台的设计摘要，不再描述尚未采用的旧阶段计划。

---

## 一、目标

Qt 前端用于人工浏览和管理 AI Memory 数据，重点覆盖以下能力：

- 查看工作记忆与最近活动
- 搜索和浏览记忆
- 查看实体与图谱关系
- 浏览和管理资产
- 导入与查看多来源会话记录

---

## 二、当前设计原则

1. 以现有 SQLite 数据和后端模块为数据来源。
2. 以 PyQt5 工作台为主，不再单独维护旧版试验方案说明。
3. 前端负责可视化与人工校验，不替代后端 CLI 的标准入口地位。
4. 文档、主题、会话支持范围应始终与实际前端一致。

---

## 三、重点视图

| 视图 | 作用 |
|---|---|
| 总览 | 展示近期活动、分布和入口导航 |
| 记忆视图 | 浏览情景、语义、程序记忆 |
| 搜索视图 | 统一搜索与结果查看 |
| 图谱视图 | 查看实体关系与聚合结果 |
| 资产视图 | 浏览和管理可复用产物 |
| 会话记录视图 | 导入并查看 Cursor、OpenClaw、Toder、Copilot 等来源 |

---

## 四、数据交互原则

- 前端与后端共享同一套数据库与存储模型。
- 数据变更应尽量通过现有后端封装完成，避免前端自行扩散数据规则。
- 当图谱、实体或资产逻辑发生变化时，文档与界面说明都应同步更新。

---

如果后续继续迭代 Qt 工作台，优先更新：

1. qt-frontend/README.md

这样可以避免前端能力已更新，但设计文档仍停留在旧阶段草案的问题。
