# AI Memory Qt UI 原型布局说明

## 当前版本状态

- 已保留原始文件：index.html（科技清爽情报台，对照稿）
- 已新增主线文件：dark-professional.html（暗色专业情报台，当前推荐方向）
- 已新增风格预览页：style-preview.html（用于后续横向浏览和比较）
- 已新增挂机观察说明：feedback-monitoring.md（用于长时 feedback 链路排查）

## 设计方向

- 原始风格：科技清爽情报台
- 当前主线风格：暗色专业情报台
- 目标体验：把记忆、会话、图谱、资产从分散功能页收拢成一条连续工作流
- 主题策略：一套布局，三套主题变量
- 第一版范围：总览、会话记录、全局搜索、记忆详情、图谱页、资产页

## 暗色专业情报台约束

- 视觉关键词：专业、克制、秩序、长时间工作、信息密度友好
- 色彩策略：深蓝灰背景 + 靛蓝/蓝色强调，不使用大面积高饱和渐变
- 结构策略：更强调边界、排版层级和信息块之间的节奏，不追求漂浮感
- 交互策略：按钮反馈、Toast、局部加载仍保留，但降低炫光和装饰性
- 适配目标：更适合会话追踪、图谱关系、资产工位这类需要长时间停留的页面

## 布局骨架

### 1. 全局框架

- 左侧主导航：承担一级页面切换，固定为低宽度情报轨道，减少页面跳转成本。
- 顶部命令条：统一入口，支持全局搜索、命令触发、最近上下文跳转、主题切换。
- 中央主工作区：承载当前页面的主要内容，保持高信息密度但避免拥堵。
- 右侧上下文面板：只在需要时显示高价值摘要、关系、状态和快捷动作。

### 2. 主题策略

- Dark：默认工作态，适合长时间操作、对比复杂信息。
- Light：阅读和整理态，适合编辑记忆、审阅内容、展示给他人。
- Mist：中性整理态，强调柔和边界和较低视觉压迫感。

## 页面说明

### 总览页

用途：作为工作台首页，不只是数据总数，而是“当前最值得进入的上下文”。

组成：

- 顶部 Hero 区：强调产品定位、主题切换、命令入口、快速跳转。
- 关键指标带：展示活跃记忆、今日会话、可复用资产。
- 核心记忆胶囊：把高价值记忆、偏好、资产放成卡片组，方便直接进入。
- 时间流与注意力：展示最近变化，并明确哪些值得继续处理。
- 右侧状态区：展示主题预览、工作台原则、加载态和空状态示例。

### 会话记录页

用途：从“对话列表”升级成“情报时间线”。

组成：

- 左栏：框架维度和会话列表，强调按真实最新会话排序。
- 中栏：时间线式 transcript，把 assistant 请求、user 回复、关键动作串起来。
- 右栏：会话结论、过滤规则、快捷操作。

重点交互：

- 不再让用户从工具折叠项找 feedback 内容。
- 低价值工具项默认隐藏，只保留补丁和关键运行命令。
- 会话标题、标签、状态可直接作为二次筛选入口。

### 全局搜索页

用途：统一检索入口，不区分先搜“会话”还是“记忆”。

组成：

- 左栏：查询摘要、过滤器、空状态引导。
- 右栏：统一结果流，混排会话、记忆、图谱节点、资产。

重点交互：

- 支持问题语句式搜索。
- 搜不到时给推荐维度而不是纯空白。

### 记忆详情页

用途：把记忆编辑从文本表单提升为“上下文编辑器”。

组成：

- 左栏：记忆胶囊堆栈，承接上一个页面的上下文切换。
- 中央编辑面：摘要、正文、强度、关联上下文。
- 右侧元信息：项目、来源、复用建议、快捷动作。

重点交互：

- 直接展示关联会话与图谱节点。
- 强度、标签、归属不用跳弹窗处理。

### 图谱页

用途：把图谱从“视觉装饰”变成工作入口。

组成：

- 左侧主画布：关系节点与边，突出当前上下文相关实体。
- 右侧侧栏：当前节点信息、关系建议、空图引导。

重点交互：

- 点击节点后可跳到会话或记忆详情。
- 关系建议用于快速补边和确认知识结构。

### 资产页

用途：把文件和产物变成“可复用单元”。

组成：

- 主区域：资产卡片网格，强调健康度、类型、标签和复用价值。
- 侧栏：推荐动作、依赖关系、校验状态。

重点交互：

- 资产不止展示路径，还要强调来源、依赖和可导出动作。
- 适合后续接入打包、验证、复用推荐。

## 视觉规则

- 卡片边界不走生硬描边，而是“半透明面 + 细边线 + 柔和阴影”的层叠结构。
- 信息层级靠字体权重、留白、颜色浓度区分，而不是靠大量分割线。
- 状态反馈必须统一：按钮忙碌态、局部骨架屏、底部 Toast、空状态引导。
- 不使用纯平白背景，始终通过渐变、光斑、网格弱纹理维持科技工作台气质。

## Qt 落地建议

- 左侧主导航、顶部命令条、右侧上下文面板适合拆成独立容器组件，便于主题变量复用。
- 主题切换建议通过统一 token 映射，而不是逐控件写死颜色。
- 会话页应优先落地中栏 transcript 结构与右栏情报侧栏，这两部分最能体现新版价值。
- Toast、忙碌态、空状态建议先做成全局交互规范，避免各页行为不一致。
