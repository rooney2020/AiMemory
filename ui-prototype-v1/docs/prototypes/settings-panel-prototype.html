小弹层适合“切主题、点导出”这种轻操作，但同步配置里已经出现 OAuth、首次补传、定时任务与安全范围，这些都需要更强的状态说明和风险提示。
兼容保留

主题与界面

原型摘要
v1
交互结构
从小弹层改为独立设置工作区。顶部按钮仍在，但承担“进入设置中心”的角色。
核心目标
减少同步误操作，让用户在真正点击“立即同步”之前就知道会发生什么。
视觉策略
完全沿用“科技清爽情报台”主题令牌，用更清晰的卡片分组替代现有竖向表单堆叠。
建议优先落地
如果后续要把原型变成真实 Qt 页面，建议先做以下三块，因为它们直接解决当前痛点。
1. 状态侧栏
让 GitHub 登录状态、上次同步结果、预计待处理体量始终可见。
2. 主题大卡预览
把当前 3 个小按钮升级成带预览的大卡，降低选择成本。
3. 风险分流
首次全量补传、敏感会话上传、重建基线统一做显式分流提示。
主题试切
用于快速比较设置中心在不同主题下的层级表现，而不需要回到主工作台再观察。
原型原则：1）延续现有左导航情报台视觉；2）设置项按任务分组；3）保存配置与执行动作分离；4）同步风险前置展示；5）支持窄屏折叠。
建议后续 Qt 实现策略：先做独立设置页，再按需保留顶部轻量快捷开关。
